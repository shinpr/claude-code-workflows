# Api Resource Cues

Consult only entries that can resolve the current question. Supplied and repository evidence come first; ask for missing access details only when required.

- **Schema**: OpenAPI, Protobuf, GraphQL or code-first definition for the affected API.
- **Mock environment**: Existing entry point and whether it preserves the claimed contract.
- **Authentication**: Mechanism and credential-source reference needed for authorized verification.
- **Schema change process**: Versioning or compatibility rule governing the changed contract.

Return the selected resource and evidence to the parent capture protocol. These cues create no obligation to survey unrelated resources.
