# Infra Resource Cues

Consult only entries that can resolve the current question. Supplied and repository evidence come first; ask for missing access details only when required.

- **IaC source**: Relevant checked-in or external infrastructure definition.
- **Environment configuration**: Configuration source for the specific environment and question.
- **Secrets**: Secret-store reference and access mechanism, never values.
- **Deployment trigger**: Existing execution/approval boundary only when it affects current implementation or verification.

Return the selected resource and evidence to the parent capture protocol. These cues create no obligation to survey unrelated resources.
