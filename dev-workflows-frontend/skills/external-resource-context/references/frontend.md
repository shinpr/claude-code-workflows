# Frontend Resource Cues

Consult only entries that can resolve the current question. Supplied and repository evidence come first; ask for missing access details only when required.

- **Design origin**: Canonical visual source or specification and the applicable node/version.
- **Design system**: Component/token documentation or package that determines this UI contract.
- **Guidelines**: A sourced usage or accessibility requirement that constrains this change.
- **Visual verification**: Existing rendering entry point, harness or access method needed to observe the UI.

Return the selected resource and evidence to the parent capture protocol. These cues create no obligation to survey unrelated resources.
